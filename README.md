# 3D 像素西安城墙夜游世界 V3.0

手机端 Three.js 3D 体素像素世界小游戏，纯前端静态页面（HTML + CSS + 原生 JS + Three.js CDN），零后端。

## 玩法

- **3D 体素沙盘**：立体「回」字形城墙（带垛口、真正能穿过去的拱形门洞、飞檐城楼+红灯笼）、下沉护城河（水波纹流动）、树林路灯街道；12 座地标各有造型（广仁寺红墙金顶+转经筒、火车站钟楼站房+绿皮车厢、咖啡馆暖光橱窗+遮阳伞、顺城巷小酒馆霓虹牌）。
- **像素纹理**：代码动态绘制 16×16 / 32×32 像素贴图（CanvasTexture + NearestFilter）：青灰城墙砖缝、石板路、草地碎花、护城河水波、暖黄灯笼、咖啡馆木纹玻璃橱窗、广仁寺红墙金瓦。
- **光影**：夜色雾效（FogExp2）+ 路灯城门灯笼暖色点光源；三套皮肤「古风夜游 / 现代夜色 / 赛博霓虹」切换天空、雾效与灯光色调。
- **操控（小米 14 竖屏）**：
  - 云逛模式：左下角虚拟摇杆走路，右半屏滑动旋转镜头；右上角一键切换第三人称追尾视角 / 第一人称沉浸视角（穿门洞、抬头看城楼）。
  - 实景模式：摇杆隐藏，小人跟随手机真实 GPS（经纬度映射到 3D 城墙坐标系）移动；角落「室内测试：模拟瞬移到朝阳门」方便验收；右半屏滑动仍可转视角。
- **高光探索**：靠近地标时 3D 建筑上方浮现旋转发光的像素星星标记，屏幕下方出现「探索：XXX」大按钮，点击播放放射状光芒再揭晓物品。
- **严格分档爆率**：
  - 云逛：只掉 3 档 70% / 2 档 30%，绝无 1 档（提示注明“第 1 档传说风物仅限线下实景触发”）。
  - 实景：3 档 55% / 2 档 30% / 1 档 15%。
- **流浪猫彩蛋**：3 只体素猫在全图随机游走，点中 30% 概率偶遇一只 V1 图鉴里的猫。
- **图鉴抽屉**：12 地标 × 3 档 = 36 件风物进度；点已收集的风物打开「像素记忆明信片」（写笔记 + 截图保存）。

## 数据与存档

- `items.json`：12 个真实地标（经纬度 + 世界坐标）+ 36 件分档风物（V2 原样保留）；GPS→世界坐标仿射参数见 `meta.gpsToWorld`。
- `cats.json`：V1 的 10 只城墙流浪猫（彩蛋用）。
- 进度、笔记保存在浏览器 `localStorage`（key：`xian-wall-world-v2`；猫沿用 `xian-wall-cats-v1`）。
- Three.js 使用 cdnjs 0.149.0 UMD 构建（`three.min.js`），需联网加载；CDN 失败时页面会提示。

## 本地运行

```bash
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

> 不要直接双击 index.html 用 file:// 打开，fetch 加载 items.json 会被浏览器拦截。
