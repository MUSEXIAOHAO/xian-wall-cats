# 西安城墙微缩像素世界 V2.0

手机端 Canvas 2.5D 俯斜视角像素大地图小游戏，纯前端静态页面（HTML + CSS + 原生 JS），零后端。

## 玩法

- **Canvas 微缩沙盘**：「回」字形青灰像素城墙、护城河（水波纹动画）、城墙外树木路灯主干道；单指拖动平移、双指捏合缩放，右下角 + / - / 回到主角位置。
- **像素小人主角**：
  - 云逛模式：左下角十字方向键 + 点地图前方地面走过去（A\* 寻路，遇护城河/城墙自动绕行、经城门过桥）。
  - 实景模式：小人跟随手机真实 GPS（经纬度映射到城墙坐标系）实时移动；角落「室内测试：模拟瞬移到朝阳门」方便在家验收。
- **高光探索**：小人走到地标旁（云逛）或真实距离 < 100 米（实景），地标亮起呼吸灯高光 +「点击探索」气泡，手动点建筑才触发掉落。
- **放射状开箱**：点击高光地标后，中央旋转放射状像素光芒（3 档翡翠绿 / 2 档幻影紫 / 1 档鎏金光），再点光芒中心才跳出风物卡片。
- **严格分档爆率**：
  - 云逛：只掉 3 档 70% / 2 档 30%，绝无 1 档（提示注明“第 1 档传说风物仅限线下实景触发”）。
  - 实景：3 档 55% / 2 档 30% / 1 档 15%。
- **流浪猫彩蛋**：3 只猫在全图随机游走，点中 30% 概率偶遇一只 V1 图鉴里的猫。
- **图鉴抽屉**：12 地标 × 3 档 = 36 件风物进度；点已收集的风物打开「像素记忆明信片」（写笔记 + 截图保存）。

## 数据与存档

- `items.json`：12 个真实地标（经纬度 + Canvas 世界坐标）+ 36 件分档风物；GPS→世界坐标仿射参数见 `meta.gpsToWorld`。
- `cats.json`：V1 的 10 只城墙流浪猫（彩蛋用）。
- 进度、笔记保存在浏览器 `localStorage`（key：`xian-wall-world-v2`；猫沿用 `xian-wall-cats-v1`）。

## 本地运行

```bash
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

> 不要直接双击 index.html 用 file:// 打开，fetch 加载 items.json 会被浏览器拦截。
