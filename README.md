# 西安城墙夜游猫猫图鉴

极简手机端像素风网页小游戏，纯前端静态页面（HTML + CSS + 原生 JS），零后端。

## 玩法

- **线上云逛模式**：点像素城墙上的 6 扇城门节点，随时随地触发猫猫掉落（每次冷却 5 秒）。
- **城墙实景模式**：浏览器定位 + Haversine 公式算与 6 个城门（永宁门、朱雀门、含光门、文昌门、和平门、长乐门）的真实距离，走近 80 米内亮起「偶遇猫猫」按钮；附「室内测试：模拟走近最近城门」调试按钮。
- **三套皮肤**：古风城墙 / 现代夜色 / 赛博霓虹，切换改变配色，并小幅提高对应气质猫猫的掉率权重。
- **图鉴**：10 只城墙流浪猫，常见 60% / 稀有 30% / 传说 10%。
- **像素记忆明信片**：点已收集的猫，弹出带时间、城门、稀有度和笔记的明信片，可写一句「今晚心情 / 偶遇笔记」，直接手机截图留念。

## 数据与存档

- `cats.json`：6 个城门的真实经纬度 + 10 只猫的花色、性格小故事、稀有度、皮肤气质。
- 收集进度、点亮记录、笔记保存在浏览器 `localStorage`（key：`xian-wall-cats-v1`）。

## 本地运行

```bash
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

> 不要直接双击 index.html 用 file:// 打开，fetch 加载 cats.json 会被浏览器拦截。
